# 아파트 급매 알림 + 시세 트래커

## 서비스 개요
관심 단지의 실거래가 변동을 자동으로 추적하고 급매 발생 시 알림을 보내는 서비스

## MVP 기능
1. 관심 단지 등록
2. 실거래가 변동 알림 (이메일)
3. 단지별 시세 타임라인

## 기술 스택
- 데이터: 국토부 실거래가 API
- UI: Lovable (React)
- DB/백엔드: Supabase
- 알림: Resend (이메일)
- 결제: Toss Payments
